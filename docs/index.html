Talk to the logs. AI agent using Google Agents Development Kit (ADK) and Gemini to query BigQuery datasets via natural language across the entire Glomar sensor ecosystem.

Cognitive Synthesis Over Fused Sensor Telemetry

ask-the-logs represents the cognitive peak of the Glomar stack. When paired with the 11 sensor pipelines—from USB scanner serial hits to LoRa mesh packets and Mirkwood cross-channel joins—it swaps domain-specific system prompts into Gemini at session start, converting plain English queries directly into valid BigQuery Standard SQL.

02 · two-tier lakehouse schema design

ask-the-logs maps the Glomar ecosystem into two distinct architectural tiers:

  • Tier 1 — Native Per-Source Tables: Raw, full-fidelity telemetry written in each tool's native format (e.g. scanner.hits from BCD325, meshnarc.packets from LoRa, adsb.transponders). Query these when investigating a single physical RF band.
  • Tier 2 — Mirkwood Unified Cross-Channel Table: Normalized cross-channel events in mirkwood.emission_events with stable SHA-256 device_fingerprint hashes, enabling spatiotemporal joins across disparate sensor families.

05 · synthetic boundaries & cost controls

To prevent operational abuse and uncontrolled compute spend:

  • Synthetic Data Envelope: The adsb and lte_cellular datasets are strictly synthetic scenario demonstrations. No physical 1090 MHz receiver or cell interceptor is touched.
  • Rate Limiting: /api/query is throttled to 10 queries per minute per authenticated OAuth identity.
  • Query Cost Guardrails: System prompts enforce mandatory time-partition filters (e.g. WHERE rx_timestamp >= TIMESTAMP_SUB(CURRENT_TIMESTAMP(), INTERVAL 24 HOUR)) to prevent accidental multi-terabyte table scans.

Frequently asked questions

What is ask-the-logs?

A natural-language interface to BigQuery. You ask a question in plain English. A Google Agent Development Kit agent with Gemini turns it into SQL, runs it, and explains the result.

What do I need to run it?

Python dependencies from requirements.txt, a Google API key, an OAuth 2.0 web client ID, and BigQuery permissions on your datasets. The .env.example file explains where to get each one. Start the server with uvicorn on port 8000 and open it in a browser.

Does it cost anything to use?

Query cost depends on how much data each query scans. The README advises adding a time filter on partitioned tables to keep costs down.

Can I add my own dataset?

Yes. Each source is one entry in sources.py, with a domain prompt that describes its schema and vocabulary, a suggested dataset, and example questions. The agent loads that prompt at session start.

Is the sample data real?

Some of it isn't. The README says which sources are synthetic, and that real captures from some tools need their own hardware.
